Self-Diagnosis: Scan Questions & Answers

Checks the master question bank and all 15 test forms for both exams — confirms every question has exactly 4 options, a valid correct answer, no duplicate options, and (most importantly) that grading actually works: it simulates always answering correctly on every single form and confirms a 100% score comes back. Run this any time something looks off with questions/answers not matching up.

Manually Assign a Test Form to a Rep

By default, each rep's exam form (1 of 15) is auto-rotated — different reps get different forms, and a single rep's repeat attempts also rotate across forms. Use this to pin a specific rep/exam to one fixed form instead (e.g. for a proctored session where everyone in the room should see the same test, or to reuse a known form). Set back to "Auto-rotate" to clear the override.
