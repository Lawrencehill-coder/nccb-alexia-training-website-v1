Award Certification to a Rep

Use this to manually certify a rep (e.g. for an in-person or proctored exam, a make-up, or a legacy record) without them logging in themselves. This creates a real attempt record — synced to the Attempts sheet — and generates their certificate immediately below.

Certificate Preview

Self-Diagnosis: Scan Questions & Answers

Checks the master question bank and all 15 exam versions for both exams — confirms every question has exactly 4 options, a valid correct answer, no duplicate options, and (most importantly) that grading actually works: it simulates always answering correctly on every single exam version and confirms a 100% score comes back. Run this any time something looks off with questions/answers not matching up.

Manually Assign an Exam Number to a Rep

By default, each rep's exam number (1 of 15) is auto-rotated — different reps get different exam numbers, and a single rep's repeat attempts also rotate across exam numbers. Use this to pin a specific rep/exam to one fixed exam number instead (e.g. for a proctored session where everyone in the room should see the same test, or to reuse a known exam). Set back to "Auto-rotate" to clear the override.
